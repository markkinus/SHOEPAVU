# SHOEPAVU

## Introduction

SHOEPAVU is a front-end shoe store website designed to showcase different footwear styles in a simple and visually appealing interface.


## Overview

The website allows users to browse footwear categories, view featured products, check prices and ratings, view product details, and access contact information.

## Problem Statement

Customers need a simple and convenient way to browse different footwear styles and access essential product information such as prices, ratings, and descriptions without visiting a physical store.

## Solution

SHOEPAVU provides a simple online footwear showcase where customers can browse different shoe categories, view product details, compare prices and ratings, and access the store's contact information in one place.

## Features

* Home, About, Products, and Contact sections
* Sneakers, Formal, Casual, and Sandals categories
* Featured product cards with prices and ratings
* CSS-based product detail modals
* Hover effects and styled buttons
* Shopping cart icon
* Contact form
* Footer with quick links and contact information

Clone the repository

Open the project
Open index.html in a web browser such as Google Chrome or Microsoft Edge.
Edit the project

Preview changes
